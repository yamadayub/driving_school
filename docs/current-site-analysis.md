## 5. 申込フォーム（現行 `/contact-application-iwataki/`）

**必須14 / 任意5 = 全19項目**。

- 必須: 教習プラン(チェック複数)、コース(普通車/準中型のみドロップダウン)、氏名、氏名カナ、生年月日(セレクト年月日)、性別(ラジオ)、メール、郵便番号、住所、電話、入所希望日(セレクト年月)、希望教習時間帯(ラジオ)、支払方法(ドロップダウン)、当校初めてか(ラジオ)
- 任意: 建物名、現有免許(チェック20種超)、免許証写真(表裏2枚アップロード)、知ったきっかけ(チェック複数)、質問・要望(テキストエリア)
- フロー: 入力 → 確認する → 送信する（送信先不透明、外部フォーム推定）

### 課題
- 項目過多で離脱リスク。生年月日セレクトが煩雑。
- **免許取消歴の申告が自由記述欄に埋没**（重要確認が見落とされる設計）。
- 現有免許20+選択肢の複数選択指示が不明瞭。
- モバイル最適化・送信先・個人情報保管が不透明。

## 9. 技術方針（確定）

- **Next.js(App Router) + Prisma + PostgreSQL、DBアクセスはサーバー限定**（公開DBキーを持たない）。
- 管理画面 Auth.js 認証・認可。免許証写真は非公開ストレージ＋署名付きURL・保存暗号化。
- フォーム: CAPTCHA + レート制限 + ハニーポット。APPI準拠の保持/削除フロー。
- ChatBot: **ルールベース/モック応答**（FAQ・料金ナレッジのスクリプト応答＋エスカレーション導線）。
