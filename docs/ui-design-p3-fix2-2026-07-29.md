## 1. 指摘の要旨

`spec-p3-fix2-2026-07-29.md:179`（申し送り D-5）は「案(A) を採用したので I-6 は**変更不要**、確認だけ」としていた。レビュワーは本文を読み、**核心（受付番号を偽って表示しない）は正しいが、I-6 が指示している画面が確定契約と食い違う**と判定した。

- I-6（旧）: 「Cookie が期限切れ（30分）になった状態での再送は `receiptNumber` を受け取れないため、その場合は完了画面ではなく **§5「保存失敗」相当の再送導線に留め**、受付番号を偽って表示しない」
- 確定契約: **Cookie の期限切れ・不在・署名不正の再送は AC-RL-13(b) により先に Tier B（`403 { challenge: "interactive" }`）で止まり、冪等照合に到達しない。** Tier B の UI は §3.2 の可視 CAPTCHA であって §5（500 系）の「保存失敗」ではない。
- 旧記述どおり実装すると `403 + challenge` に「送信できませんでした」型の画面が出て、**§10 テスト項目11（Tier B の4経路で画面テキストが完全に一致する）に落ちる**。

## 2. 修正内容

### 2-1. §11 I-6 の「回答」欄を書き換え（`form-submission.md:506`）— 指摘への直接対応

| 項目 | 旧 | 新 |
|------|----|----|
| Cookie 期限切れ時の再送の扱い | §5「保存失敗」相当の再送導線 | **§3.2 の Tier B UI（可視 CAPTCHA）**。冪等照合に到達せず AC-RL-13(b) で先に止まることを明記。§5 型のエラー画面を出すことを**禁止**（テスト項目11 に落ちる理由付き） |
| `receiptNumber` が返らない条件 | 「Cookie が期限切れになった状態での再送」（不正確） | **「Cookie は有効だが `sid` が一致しない」再送のみ**（別セッションからのキー提示 / `sessionIdHash` が `null` の行） |
| 照合の実体 | 記載なし | `Application.sessionIdHash`（`sid` の HMAC）との**定数時間比較**・**`null` は不一致**（SPEC-017 / RV-P3DR-002） |
| 結論 | 受付番号を偽って表示しない | **不変**（§6 の防御的分岐へリンク） |

**旧記述が誤りであった旨を欄内に ⚠️ 付きで明示的に残した。** 「変更不要」と申し送られた項目なので、次に読む人（P4 の再評価者 / Impl）が「なぜ変わったか」を追えるようにするため。

### 2-2. §6 に防御的分岐を1項追加（`form-submission.md:415-420`）— 修正の副次的必要

I-6 で「Cookie 期限切れ → Tier B」を確定した結果、**`200 { idempotent: true }` に `receiptNumber` が無い応答が到達する条件が「`sid` 不一致」だけに絞られた**。Impl は UI 設計を実装の一次入力にするため、この分岐で何を描くかを書かないと発明される。以下を定義した。

- 受付番号カードを**描画しない**（空欄 / `—` / 仮採番 / `id` の代用を一切禁止）。コピーボタンも出さない。
- 見出し「お申込みは受け付け済みです」+ 「受付番号は控えメールをご確認ください」+ 電話導線。**「送信できませんでした」型の文言を使わない**（実際には受け付けられており事実と異なるため）。
- `data-submission-state="done"` のまま（§10 項目10 の「Tier 判別は HTTP ステータスのみ」を崩さない）。
- **再送ボタンを出さない**——同一キーの再送は同じ応答を返すだけで、押させると抜けられないループになる（RV-P3DR-004 (e) と同型の失敗を UI 側で作らないため）。
- 完了時の副作用（下書き削除 / `beforeunload` 解除 / `revokeObjectURL` / `idempotencyKey` 破棄）は通常の完了画面と同一に実行する。

### 2-3. §10 にテスト項目17を追加（`form-submission.md:485`）

上記分岐を Test Agent が検証できる形にした。あわせて **「Cookie 期限切れの再送はこの経路ではなく `403 { challenge }`（項目11・12）」** を明記し、両者を取り違えたテストが書かれることを防いだ。
