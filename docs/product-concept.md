# 岩滝・網野自動車教習所 Webサイトリニューアル — Product Concept

## One-liner

**現行サイトの主要コンテンツを引き継ぎつつ、「管理者が自分で更新でき・申込がしやすく・AIが24時間質問に答え・検索で見つかる」モダンな教習所サイトのデモ。**

地方の自動車教習所（岩滝校・網野校）向けに、CMS・申込フォーム・AIチャットボット・SEO対応を統合したWebサイトリニューアルのProof of Concept。

---

## Background（背景）

現行サイト <https://iwataki-driving-school.com/> は、通学・合宿・プロ免許・ドローン・建機講習まで扱う総合教習所の情報を網羅しているが、以下の運用・体験課題を抱える。

- **更新が事業者主導でできない**: お知らせ・料金・キャンペーンの更新に制作会社の手が必要と推測され、情報鮮度が落ちる（「お得な情報」が約2ヶ月間隔でしか更新されない等）。
- **申込フォームの離脱リスク**: 必須14項目・合計19項目の長大フォーム。重要な注意事項（免許取消歴の申告）が自由記述欄に埋没。モバイル最適化が不明瞭。
- **問い合わせが電話・LINEに依存**: 定型質問（年齢・持ち物・視力・支払い・送迎バス等）が営業時間外に自己解決できない。FAQは11件と限定的。
- **SEO・構造化の弱さ**: 2校×多数の免許種別を持つが、ローカルSEO（LocalBusiness/DrivingSchema）、メタ最適化、内部リンク設計が最新水準ではない可能性。

本Productは、これらを解決した「運用まで含むリニューアル像」を、実際に触れるデモで提示する。

## Target User（対象ユーザー）

### 1. サイト利用者（エンドユーザー）
- **免許取得検討者**: 18歳前後の学生、社会人、Uターン層。通学 or 合宿を比較検討中。
- **プロ免許・法人ニーズ**: 大型・二種・けん引・大型特殊、建機/ドローン講習を必要とする在職者・法人。
- **保護者・付添い**: 料金・安全性・アクセスを確認する層。
- 主なデバイスは **モバイル**。空き時間に料金比較 → 申込 or 質問という導線。

### 2. サイト管理者（教習所スタッフ）
- ITに専門的でない事務スタッフ。**専門知識なしでお知らせ・料金・FAQを更新**したい。
- 申込・問い合わせを**管理画面で一覧・ステータス管理**したい。

---

## Job（ユーザーが実現したいこと）

### エンドユーザーのJob
> **自分に合ったコース・料金・校舎を素早く比較し、疑問を解消して、迷いなく申込（または相談）まで進む。**

### 管理者のJob
> **制作会社に依頼せず、自分たちのタイミングでサイトの情報を最新に保ち、届いた申込・問い合わせを取りこぼさず対応する。**

---

## Pain（現行の痒み）

| # | Pain | 現行サイトでの現れ方 |
|---|------|------------------|
| 1 | **情報更新が自分でできない / 遅い** | お知らせ・料金・キャンペーンの更新が滞りがち。季節キャンペーンの反映が遅れ機会損失 |
| 2 | **申込フォームが長く離脱しやすい** | 必須14 / 全19項目、生年月日セレクト地獄、重要注意が自由記述に埋没 |
| 3 | **営業時間外に疑問が解決できない** | 問い合わせが電話・LINEに集中。FAQ 11件では定型質問をカバーしきれない |
| 4 | **検索で見つかりにくい / 訴求が弱い** | ローカルSEO・構造化データ・メタ最適化が最新水準でない可能性 |
| 5 | **2校・多免許種別の情報が探しにくい** | 校舎ごとの対応免許・料金・アクセスの横断比較がしづらい |

## Solution

現行の主要コンテンツ（トップ / 通学 / 合宿 / プロ免許各種 / ドローン・建機 / お知らせ / FAQ / 学校案内 / アクセス / リクルート）を**情報設計を整理して維持**した上で、以下4つの新価値を追加する。

### A. 公開サイト（モダンリニューアル）
- 現行コンテンツを再構成したレスポンシブ・高速なサイト。
- コース・料金の**横断比較UI**（校舎×免許種別×通学/合宿）。
- 卒業生の声、特徴（指名制・女性教習・スマホ予約・送迎バス）を訴求。

### B. 管理画面（CMS / セルフ運用）
- **お知らせ**のCRUD（カテゴリ: 岩滝 / 網野 / ドローン / 建機 / ALL）。
- **料金・コース**の編集（種別・料金・最短日数・対応校・給付金/助成金タグ）。
- **FAQ**の編集（AIチャットボットのナレッジと連動）。
- **申込・問い合わせ**の一覧・ステータス管理（新規/対応中/完了）。

### C. 入所申込・問い合わせフォーム（改善版）
- **ステップ式**フォームで19項目の心理的負担を分割・削減。
- 免許取消歴などの重要確認を**独立した必須設問**に格上げ。
- 免許証写真アップロード、入力途中保存、確認画面、モバイル最適化。

### D. AI ChatBot（24時間自己解決）
- FAQ・料金・アクセス・コース情報をナレッジ化した**RAG型チャットボット**。
- 「18歳未満でも入れる？」「送迎バスは？」「AT/MTどっち？」等に即答。
- 解決しない場合は**申込フォーム / LINE / 電話へエスカレーション**。

### E. SEO対応
- ページ別メタ（title/description）、OGP、正規URL。
- **構造化データ**（`DrivingSchool` / `LocalBusiness` × 2校、`FAQPage`、`BreadcrumbList`）。
- サイトマップ、内部リンク設計、Core Web Vitals配慮。

## SolutionがどうPainを解決するか

| Pain | 解決 |
|------|------|
| 情報更新が自分でできない | CMSで管理者が即時更新。公開まで数分 |
| 申込フォームが長い | ステップ式・入力補助・保存で離脱を低減。重要確認を可視化 |
| 時間外に解決できない | AI ChatBotが24時間対応、未解決は人へエスカレーション |
| 検索で見つかりにくい | 構造化データ・メタ・内部リンクでローカルSEO強化 |
| 2校情報が探しにくい | 校舎×免許種別の横断比較UIで即座に自分向け情報へ |

## Demo Scope（このデモで示す範囲）

**In Scope（デモで動くもの）**
- 公開サイトの主要ページ（トップ / コース・料金比較 / お知らせ一覧・詳細 / FAQ / 学校案内・アクセス / 申込フォーム）
- お知らせCMS（CRUD）+ 申込・問い合わせ管理（一覧・ステータス）
- ステップ式 入所申込・問い合わせフォーム（送信 → 管理画面反映）
- AI ChatBot（FAQ/料金ナレッジによる応答 + エスカレーション導線）
- SEO基盤（メタ / OGP / 構造化データ / サイトマップ）

**Out of Scope（デモでは非対象）**
- 実決済・ローン審査連携
- 実際の教習予約システム（既存の外部予約 menkyo-torocca 等）との本番連携
- 本番の会員認証・個人情報の実運用保管
- 多言語UI（構造としては将来対応を想定）
- リクルート応募の本番運用、法人契約の実ワークフロー
