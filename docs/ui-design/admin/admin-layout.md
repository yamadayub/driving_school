# UI設計: 管理画面 共通レイアウト（Sidebar / Header / 認証ガード）

> 準拠: `/DESIGN.md`。トークン・Badgeコンポーネントは公開サイト（`../layout.md`）と共通のものを再利用し、ここでは**管理ツールとしてのシェル**のみを定義する。
> 対応要件: `functional-spec.md` F-012（認証）, F-013（ダッシュボード）, §4.2 認証・認可
> 適用範囲: `/admin/**`（`/admin/login` を除く）。**このレイアウトが描画される時点で Auth.js セッションが有効であることが前提**（`middleware` が `/admin/**` を保護し、未認証は `/admin/login` へリダイレクト済み。F-012 E-012-2）。ログイン画面自体は本レイアウトを使わない専用シェル（`login.md` 参照）。

## ビジュアルコンセプト

- 公開サイトの「明るく前向き」なトーンとは意図的に切り離し、**機能的・高密度・可読重視**の管理ツールトーンにする。マーケティング的な装飾（Hero写真、グラデーション、マイクロインタラクションの"Juice"）は使わない。
- 一目で「今どの管理機能を開いているか」「自分は誰としてログインしているか」が分かることを優先する。
- 公開サイトと視覚的に区別しつつ、色・フォント・spacing token は完全に共用し、ブランドとしての一貫性は保つ（別デザインシステムを作らない）。

## レイアウト構成

### Desktop / Tablet（≥768px、管理画面はこの帯を主対象とする）

```
┌───────────┬──────────────────────────────────────┐
│           │ Topbar: Breadcrumb          [田中 花子 ▾ ログアウト] │
│  Sidebar  ├──────────────────────────────────────┤
│ (dark,    │                                        │
│  240px)   │              <page content>            │
│           │                                        │
│ ロゴ/サイト名 │                                        │
│ ダッシュボード│                                        │
│ お知らせ    │                                        │
│ 料金・コース(準備中)│                                  │
│ FAQ(準備中) │                                        │
│ 受信管理(準備中)│                                     │
│           │                                        │
│ ―――――――― │                                        │
│ 公開サイトを見る│                                       │
└───────────┴──────────────────────────────────────┘
```

### Tablet 縮小時（768–1023px）

- Sidebar を幅72pxのアイコンのみ表示に自動縮小（ラベルは `title` 属性でツールチップ表示）。ハンバーガーで一時的にラベル付きへ展開可能。

### Mobile（≤767px、公式サポート外だが破綻しないことを保証）

- Sidebarはドロワー化し、公開サイト `../layout.md` §2 の `NavDrawer` と同じ開閉パターン（全画面オーバーレイ、フォーカストラップ、`Esc`で閉じる）を流用する。
- CMSの編集フォーム・DataTableはモバイルでも横スクロールで破綻しない最低限の対応のみ行い、快適な編集体験はDesktop/Tabletを正とする（管理者は事務スタッフのPC/タブレット利用を主想定、`product-concept.md`ペルソナ準拠）。

## Sidebar

- 背景: `#111827`（公開サイト Footer と同一トークンを再利用。「管理ツールらしい引き締まった帯」を新規トークンなしで表現する）。
- テキスト: `#F8FAFC`、非活性項目は `rgba(248,250,252,0.6)`。
- 現在地の項目: 背景 `rgba(255,255,255,0.08)` + 左端に4px の Primary 500 (`#3B82F6`) アクセントバー + `aria-current="page"`。
- 「準備中」項目（料金・コース/FAQ/受信管理、F-015〜F-017が未実装のため）: クリック不可（`aria-disabled="true"`、`cursor: not-allowed`）、テキストは非活性トーン、行末に小さく「準備中」ラベル（Caption, `rgba(248,250,252,0.5)`）を添える。**Badgeコンポーネントは使わない**（これは役割識別ではなく単なる状態注記のため、Badgeの意味を薄めないよう通常テキストで表現する）。
- 最下部: 「公開サイトを見る」リンク（新規タブ, 外部リンクアイコン付き、`target="_blank" rel="noopener noreferrer"`）。管理者が公開結果をすぐ確認できる導線。

### コンポーネント契約
```ts
AdminSidebar:
  props: { currentPath: string }
  // ナビ項目は静的定義（お知らせ=有効、他3項目=disabled）
```

## Topbar

- 左: `Breadcrumb`（公開サイト `../layout.md` §6 と同一コンポーネントを再利用。例: `ダッシュボード ＞ お知らせ ＞ 編集`）。
- 右: 現在ログイン中の管理者名 + ドロップダウン（「ログアウト」のみ、F-012）。
- 背景 `#fff`、下部 `1px solid #E5E7EB`、高さ64px。

### コンポーネント契約
```ts
AdminTopbar:
  props: { breadcrumbItems: { label: string; href?: string }[]; adminName: string; onLogout: () => void }

AdminUserMenu ("use client"):
  props: { adminName: string; onLogout: () => void }
  // クリックでポップオーバー展開、Escで閉じる、フォーカス管理はlayout.md NavDrawerと同じ規約
```

## ページコンテンツ領域

- 背景: `#F8FAFC`（公開サイトの Background トークンと共通。ワークスペースらしい落ち着いたグレー）。
- コンテンツ幅: `max-width: 1280px`（公開サイトの1120pxよりやや広く取り、DataTableの列を確保する）。
- ページ見出し: `SectionHeading`（`../layout.md` §7.4 を再利用、`align="left"` 固定、管理画面では `eyebrow` は基本使わない）。

## ログアウト

- `AdminUserMenu` から「ログアウト」選択 → 確認なしで即座にセッション破棄（破壊的だが取り消しが容易な操作のため確認ダイアログは不要と判断。編集中データがある場合のみ後述の離脱確認と連動させる余地あり、今回は対象外）。
- ログアウト後 `/admin/login` へリダイレクト。

## 認可・エラー状態

| ケース | 対応（F-012準拠） |
|--------|------|
| E-012-2 未認証で `/admin/**` アクセス | middlewareが`/admin/login`へリダイレクト（本レイアウトは描画されない） |
| E-012-3 セッション切れ中の操作 | APIが401を返す → クライアントが「再ログインしてください」のトースト表示後 `/admin/login?callbackUrl=...` へ誘導（元のページへ復帰できるようcallbackUrlを保持） |

## アクセシビリティ

- `<nav aria-label="管理メニュー">`（Sidebar）、`<main id="main">`（コンテンツ領域）、`<header>`（Topbar）のランドマークを明示。
- Disabled なSidebar項目はTab移動でフォーカスされるが操作不可であることが分かるよう `aria-disabled` + 視覚的な非活性トーンを両方付与する（フォーカス自体は許可し、スクリーンリーダーが「準備中」である旨を読み上げられるようにする。`tabindex="-1"`で完全除外はしない）。
- フォーカスリングは公開サイトと同一トークン（`outline: 2px solid #1D4ED8`）。
